# freeCodeCamp Responsive Web Design Projects

A collection of projects I submitted* for freeCodeCamp's Responsive Web Design curriculum — both Certification Projects and Lab Projects.

**[Visit the homepage (Personal Portfolio)](https://gafiegarcia.github.io/freecodecamp-responsive-web-design-projects/)**

## What is this?

This repo contains (almost) *all projects* (which solutions I remembered to download) I've submitted throughout the Responsive Web Design curriculum, with the last Lab project, [Build a Personal Portfolio](./index.html) being the [*homepage*](https://gafiegarcia.github.io/freecodecamp-responsive-web-design-projects/) (index.html) deployed on GitHub Pages, displaying all 26 projects.

Early in my study on fCC, I realized my perfectionistic tendencies and noticed how I always wanted every content to be *real/actual* or *relevant*. I hate placeholders. Kinda wished I had just blazed through it though, saving some time...(it took me ~5 months while working full-time to finish this)

## Projects

26 projects in total, organized by chapter:

- **HTML** — 7 projects. The fundamentals.
- **CSS** — 15 Lab projects and 4 Certification projects. Each one building on the last. This is where I went from *zero styling* to *try-hard designer* (lol). Really satisfied with the redesigned [Panasonic Lumix S5](CSS-chapter/Certification-Projects/build-a-product-landing-page.html) landing page, [technical documentation](CSS-chapter/Certification-Projects/BMP_v2.1_Documentation_Page.html) for a workflow I use at work, and the [Frieren Tribute Page](CSS-chapter/Lab-Projects/Lab-Projects/(frieren)build-a-tribute-page.html); and lastly, the one I'm most satisfied with, this repo's homepage on GitHub Pages: [Build a Personal Portfolio](https://gafiegarcia.github.io/freecodecamp-responsive-web-design-projects/) (index.html in root).

I never settled for only fulfilling the minimum requirements; gave my all, designed every project to the best of my ability despite zero design knowledge.

## Built with

All written in pure/vanilla/plain `HTML` and `CSS`. No JS nor frameworks yet. 

Some things I picked up (and heavily relied on) along the way: 

- CSS custom properties
- `clamp()` for responsive typography (still too reliant on too many media queries tho)
- Flexbox and Grid (mostly flex all the way), 
- mobile-first approach
- WebP image optimization (some of my pages needed 10 seconds to load before this), and 
- accessibility practices (`aria` attributes, `prefers-reduced-motion`, semantic HTML).
