## Projects

25 projects in total, organized by chapter:

- **HTML** — 7 projects. The fundamentals.
- **CSS** — 14 Lab projects and 4 Certification projects. Each one building on the last. This is where I went from *zero styling* to *try-hard designer* (lol). Really satisfied with the redesigned [Panasonic Lumix S5](CSS-chapter/Certification-Projects/build-a-product-landing-page.html) landing page, [technical documentation](CSS-chapter/Certification-Projects/BMP_v2.1_Documentation_Page.html) for a workflow I use at work, and the [Frieren Tribute Page](CSS-chapter/Lab-Projects/Lab-Projects/(frieren)build-a-tribute-page.html).

All written in pure/vanilla/plain `HTML` and `CSS`. I never settle for only fulfilling the minimum requirements; I always gave my all, designed every project to the best of my ability despite zero design knowledge.

## Built with

No JS nor frameworks yet. Just HTML and CSS.

Some things I picked up (and heavily relied on) along the way: CSS custom properties, `clamp()` for responsive typography, Flexbox and Grid, mobile-first approach, WebP image optimization (some of my pages needed 10 seconds to load before this), and accessibility practices (`aria` attributes, `prefers-reduced-motion`, semantic HTML).
