Welcome, (to my first-ever portfolio page)

Introduction Projects

introduction

Hi, Gafie Garcia here; a full-time videographer at Sobat HAPE, music enthusiast, and lastly, an aspiring web developer.

Usually, this "about me" section contains brief introductory, LinkedIn-style self-flattering poetic words about how one is positioning themself as a professional. However, as a beginner who hasn't even finished his first certification on freeCodeCamp, the most narcissistic thing I can do right now is sharing all the projects I've done for freeCodeCamp's Responsive Web Design Curriculum to the world — and, well, at least, for once, finally have something to show for myself.

projects

Made with love

While all lab and certification projects on freeCodeCamp proved to be quite challenging, I never settle for only fulfilling the minimum requirements; I always gave my all, designed every project to the best of my ability despite zero design knowledge. All written in pure/vanilla/plain HTML and CSS.

Personal favorites

Build a Product Landing Page

project

A redesigned landing page for Panasonic Lumix S5, the camera I use for day-to-day work for almost 4 years. All contents were taken from Panasonic Indonesia's website. While working on this project, there was a time when I really thought I was wandering to some real websites; it's probably safe to say that this is my best work as of now.

Build a Technical Documentation Page

project

Created a documentation for a real "program" (a fancy word for project instruction of an AI workflow) I use at work: B-roll Marking Program which turns YouTube video scripts into shotlists with shooting angle color-coding.

Build a Tribute Page

project

A tribute page for Frieren. The first project that gave me the opportunity to explore design freely with little-to-no constraints in the requirements. Satisfied with the result, I continued to give 100% effort towards the design of all subsequent projects.

All projects

Chronological timeline of my coding learning journey, project to project, from HTML to CSS chapter (some projects were not saved). Scroll through to see how I incrementally went from zero styling to try-hard designer.

HTMLchapter

Build a Travel Agency Page
project

The first fCC project I saved. Pure HTML. I just realized that, even since then, I've been ambitious with working on fCC projects, actually putting in relevant content even when not required.

Build a Video Compilation Page
project

An exercise of using <iframe> elements to embed videos. Went to YouTube and listed the three videos showing that are of different categories (just so that the headings make sense...).

Build a Book Catalog Table
project

An exercise of using HTML <table>. And yeah; I put the top 5 self-help books from my Notion database, just because... again... relevance.

Build a Survey Form
project

Just an exercise on HTML <form>. No styling yet, but I'm sure I tried so hard to make the questions and options relevant...

Build a Checkout Page
project

If I recall correctly, the only purpose of this project was to introduce a use case of aria-hidden and aria-describedby attributes — seemingly insignificant but important accessibility stuff.

Design a Movie Review Page
project

As another project from the Accessibility module, it presented a use case for the aria-hidden attribute. Also learned how to manually create rating visualization. Again, had to go with relevant content, which is the anime I was currently watching at the moment...

Build a Multimedia Player
project

Learned how to properly utilize <audio> and <video> elements plus important accessibility tip: always provide a transcript for content that is only accessible through audio.

CSSchapter

Build a Stylized To-Do List
project

The first time I had the chance to really mess around with CSS and designed my own color palette. Really thought it was my best work at that point that I named it "Ultimate"...

Design a Blog Post Card
project

Instead of going through my usual ambitious designing route, I tried doing some copywriting instead. The styling was basically dictated to the teeth by the test requirements so it looks just like the given example; nothing special here. (to be honest, this looks just like any other google ads pop-up)

Build an Event Flyer Page
project

The first time I started embracing my personal bias towards dark theme (and my love for Garamond typeface and newly-found interest in typography). Using my favorite event as the content, I tried unorthodox border styling for the sections; it doesn't look good, but not that bad either.

Build a Job Application Form
project

Tried designing a coffee-themed page since the only workplace I could think about was coffee shop. Learned about how to style buttons in different ways.

Design a Set of Colored Boxes
project

Strict requirements; minimal improvisation. Managed to make it look a tad bit better though...

Design a Contact Form
project

Ugly. Just ugly. I initially imagined that using radial-gradient would make the form stand out, but I guess poor choice of color ruined it. My perfectionist self was screaming about making it better, but I decided to move on to the next lesson to not waste time. At least I learned more about button and input elements usage and styling (and how to vertically center an element).

Design a Feature Selection Page
project

Learned about creating custom checkboxes and managed to make the it look quite decent. The hover and focus states are in conflict, but I didn't bother with it (not in the requirements). For the sake of "relevance" I researched about audio interface features and chose potentially optional ones.

Build a Confidential Email Page
project

Strict requirements; almost zero improvisation. Learned about absolute positioning and CSS filter.

Design a Pricing Plans Layout Page
project

Tried so hard to make it look good but realized that having learned nothing about design means I shouldn't get disappointed if I don't create a perfect-looking design. Learned about using CSS Flexbox and ::before pseudo-element here.

Build a Page of Playing Cards
project

One of the designs I'm satisfied with. My font knowledge and collection added an artistic touch to the design and made it look special. It took me a while to get the green color that looks just right... Aside from all that, I love how this one fCC project really turned CSS flexbox from a concept to being part of my arsenal.

Build a Newspaper Article
project

This project taught various font-related properties and a pseudo-element. There's room for much improvement, of course; however, this just shows the level I was with design at the moment.

Build a Tribute Page
project

A tribute page for Frieren. The first project that gave me the opportunity to explore design freely with little-to-no constraints in the requirements. With great passion, comes greater learning: image hosting, image-based design, AI-generated image, hover state transition, font pairing, flexbox mastery, and so on. And to top it all of, looking at this page puts a smile on my face.

Build a House Painting
project

I've never had a talent for painting/drawing, so I was very happy knowing what I could draw programmatically. If I didn't exercise self-restraint, I would've gone ahead and drawn some trees, fences, etc etc... The lightbulb under the awning and the chimney smoke are nice touches, but the border trick making a nice looking reflection on the windows is more satisfying to look at.

Build a Book Inventory App
project

An attempt to clone Notion database view as close as possible. Frustratingly, the requirements was quite constraining, and the test required the code to only have exactly one table, so the rest were ditched in the submitted code. It made me realize how limited (but powerful) CSS is with no JS. (I swear the mistyped header text was way funnier back then...)

Build a Technical Documentation Page
project

Created a documentation for a real "program" (a fancy word for project instruction of an AI workflow) I use at work: B-roll Marking Program which turns YouTube video scripts into shotlists with shooting angle color-coding (so much for relevance). Noticed an issue with the overall design being too dark, but satisfied with the result nonetheless, especially its responsiveness.

Build an Availability Table
project

An attempt at cloning the design of TickTick calendar as close as I could within the constraints of the requirements. Learned more about relative positioning for text (which sometimes is manual precision work). The simple grid-line design (not sure what to call it) was "okay" and the responsiveness is good enough.

Design a Newspaper Layout
project

In the (consistently-kept) spirit of being relevant, I scraped the content from bettersax.com and cherry-picked articles that piqued my interest. I learned to design based on context; I was half-satisfied with how it looks (and how unresponsive the fCC requirements made it), but realized the context of this project is to design a newspaper layout — not a web page layout.

Build a Product Landing Page
project

A redesigned landing page for Panasonic Lumix S5, the camera I use for day-to-day work for almost 4 years. While working on this project, there was a time when I really thought I was wandering to some real websites; it's probably safe to say that this is my best work as of now. Through this, I learned some limitation of CSS-only scroll interactivity.

swipe / shift+scroll

and lastly, this page: Build a Personal Portfolio. Definitely went (too) far beyond what I was taught, but nonetheless satisfied with the result. It's the first time my code didn't pass fCC test not because of requirements fulfillment, but because the code exceeds the upload size limit of the fCC web app (lol).
